The finished file is the easiest part to fake.

Similarity checkers compare final submissions, and AI tools now produce final submissions on demand. What’s much harder to produce is the afternoon behind one: the false starts, the deleted lines, the test that finally passed at 11:40 p.m.

Same file. Two histories.

Both end in exactly the same bytes. Only one of them is an evening of work.

Two recordings of the same assignment. In the first, a student types the file over an evening, runs the tests, gets stuck, deletes a function and writes it again, and the tests pass at 23:40. In the second, the editor sits in the background for two and a half hours, then the whole file arrives in a single paste. Both final files are identical.

Every edit is a link.

The recorder writes down every change, paste, save and switch of focus. Each event is sealed to the one before it, and every hundred events it signs a checkpoint, like the orange link. The record runs in one unbroken line, from the first keystroke to the hand-in.

Change one link, and the chain says so.

Rewrite a single event after the fact and its seal stops matching. Every event after it stops verifying, all the way to the end.

Covering it up doesn’t work either.

Recompute every hash after the edit and the chain looks whole again, right up to the signed checkpoint. Its signature no longer matches, and a new one takes the recorder’s signing key.

trails.slog Chain verified.

    Built not to accuse.

    Provenance surfaces patterns for a person to look at. Everything about it is designed so that honest work stays out of the way.

    Moving your own code isn’t copying.

    A paste that matches code you already typed is recognized as a move. It drops out of the review queue, and stays on the record.

    high Paste of 6 lines into trails.py

    Missing evidence is never evidence.

    A check that can’t run reports that it was skipped. It never reports a failure it couldn’t see.

    chain intact seal valid checkpoints: skipped

    Your course sets the rules.

    Staff can weight or switch off every signal, and a course can turn some kinds of capture off before anything is recorded.

    A person decides.

    Every flag opens the exact moment in the replay. Nothing happens automatically, and nothing is a verdict.

    A flag is a question, not a verdict.

    Grade the work. See the process.

    The replay shows where a student got stuck, what they tried, and when it clicked. Office hours can start from the actual evening, not a guess about it.

    One record. Every tool.

    Three editors write the same signed log. Everything downstream reads it. Every piece is open source.

    Record

    provcode Provenance for VS Code The original recorder. On the VS Code Marketplace. provjet Provenance for JetBrains IntelliJ, PyCharm, CLion and the rest. On the JetBrains Marketplace. provnvim Provenance for Neovim Pure Lua, no native dependencies.

    Hand in

    The signed bundle The log, sealed with a per-session key. One format, from every editor.
    provgate Gradescope gateway Pulls new submissions from Gradescope into the server, on a schedule.

    Check

    provd Provenance server Ingests a whole cohort, verifies every chain and signature, then keeps the log and drops the source. A documented API for everything else.

    Review

    provlens Provenance analyzer The cohort, the replay, and every signal. It can also run entirely in a browser, on a single dropped file.

    One folder. Nothing else.

    The recorder watches the assignment folder and nothing else on the computer. If you did the work, the record is the best evidence you have that you did it.

    Recorded

    • Edits and pastes in the assignment folder
    • Saves, opened files and editor focus
    • Commands run in the editor’s terminal
    • Which editor extensions are installed

    Never recorded

    • Anything outside the assignment folder
    • Your browser, screen, camera or other projects
    • Keystrokes at the system level
    • Your clipboard, unless you paste into the work
    • Offline. No network requests while you work.
    • Yours to read. The log is plain text, on your computer until you hand it in.
    • Open. Every line of the recorder is public.
    • Not forever. Stored logs are deleted on a schedule your school sets.

      What it can’t do.

      No log is impossible to forge. Someone with enough time and skill can fake one, and our own design documents say so. Provenance is built so the easy shortcuts leave marks, and the hard ones cost more effort than the assignment. The source is public, and the design assumes it.

      “We will know if you do something obvious, and we will know enough to ask questions if you do something subtle.”

      Provenance design document, section 6
